더 차분한 TV. 함께 작동하는 세 부분: **TV Doctor**(버튼 하나로 TV 정리·최적화, 코드 불필요), **Lume**(Android TV, Google TV, Fire TV용 홈 화면), **Lume Cast**(가사와 화면 미러링을 지원하는 AirPlay 수신기).

## 시작하기

1. 이 저장소를 다운로드(**Code** 후 **Download ZIP**)하고 압축을 풉니다.
2. `tv-doctor` 폴더에서 **TV Doctor.command**(Mac) 또는 **TV Doctor.bat**(Windows)를 더블클릭하세요. Linux에서는 `./tv-doctor.sh`를 실행합니다.
3. 화면의 안내를 따르세요. TV를 찾고 바뀔 내용을 보여준 뒤 사용자의 확인을 기다립니다. 모든 변경은 같은 페이지에서 되돌릴 수 있습니다.

TV에서 아무것도 삭제되지 않습니다. 앱은 비활성화만 됩니다.

### 스마트폰을 리모컨으로

Lume에서 제어 센터의 전화 버튼을 누르세요. 코드를 스캔하고 숫자를 입력하면 Apple TV 리모컨 같은 화면이 열립니다(밀어서 이동, 탭하여 선택, 길게 눌러 메뉴). 볼륨, 앱, 검색, 프로필, 원터치 장면도 있습니다. “휴대폰에서 앱 열기”를 한 번만 허용하세요(TV Doctor가 대신 해 줍니다).
