もっと穏やかなテレビへ。連携する3つの部品：**TV Doctor**（ワンボタンでテレビを掃除・最適化、コード不要）、**Lume**（Android TV・Google TV・Fire TV向けホーム画面）、**Lume Cast**（歌詞表示と画面ミラーリング対応のAirPlayレシーバー）。

## はじめかた

1. このリポジトリをダウンロード（**Code**、続けて **Download ZIP**）して解凍します。
2. `tv-doctor` フォルダーで **TV Doctor.command**（Mac）または **TV Doctor.bat**（Windows）をダブルクリック。Linuxでは `./tv-doctor.sh` を実行します。
3. 画面の案内に従ってください。テレビを見つけ、変更内容を示し、あなたの承認を待ちます。変更はすべて同じページで元に戻せます。

テレビから何もアンインストールしません。アプリは無効化されるだけです。

### スマートフォンをリモコンに

Lume で、コントロールセンターの電話ボタンを押します。コードを読み取って番号を入力すると、Apple TV リモコン風の操作面が開きます（スワイプで移動、タップで選択、長押しでメニュー）。音量、アプリ、検索、プロフィール、ワンタップのシーンも使えます。「スマートフォンからアプリを開く」を一度だけ許可してください（TV Doctor が代わりに行います）。
