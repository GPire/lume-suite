## How a file becomes ours

1. Write down what the file does (its behaviour and its inputs), not how Hume does it.
2. Write it again from that description, without Hume's file open.
3. Check it on the TV with the screens tool (`lume/tools/screens.sh`) and the phone remote.
4. Run this script: the row drops to ours.

Until a file is rewritten it keeps Hume's notice (see `lume/NOTICE`).
