# Privacy

No account, no analytics, no advertising identifiers, no crash reports sent anywhere.

What leaves the device, and only when the feature is used:

| Feature | Sent | To |
|---|---|---|
| Automatic weather place | The device's public IP address (to guess a city) | ipapi.co, ipwho.is, geojs.io (first that answers) |
| Weather and city search | City name or coordinates, language | open-meteo.com |
| Markets | Ticker symbols | query1.finance.yahoo.com |
| News | Nothing about you; plain feed requests | The newsrooms' RSS servers, and ansa.it for regional news |
| Film and series search and shelves | Search text, country, language | JustWatch, TMDB |
| Paintings | Picture requests | Wikimedia Commons |
| Lyrics (on by default; one switch in Settings and in the quick menu turns them off) | Song title, artist, album and length | lrclib.net |
| TV Doctor | Nothing about your TV. Package lists are downloaded, not uploaded. | The package list is fetched from GitHub the first time |

TV Doctor's page runs only on your own computer (127.0.0.1). Its backups of what it changed stay in a folder on that computer.
