Ein ruhigerer Fernseher. Drei Teile, die zusammenarbeiten: **TV Doctor** (reinigt und optimiert den Fernseher mit einem Klick, ohne Code), **Lume** (Startbildschirm für Android TV, Google TV und Fire TV) und **Lume Cast** (AirPlay-Empfänger mit Songtexten und Bildschirmspiegelung).

## So starten

1. Lade das Repository herunter (**Code**, dann **Download ZIP**) und entpacke es.
2. Doppelklicke im Ordner `tv-doctor` auf **TV Doctor.command** (Mac), **TV Doctor.bat** (Windows) oder starte `./tv-doctor.sh` (Linux).
3. Folge dem Bildschirm: Er findet den Fernseher, zeigt die geplanten Änderungen und wartet auf dein OK. Jede Änderung lässt sich auf derselben Seite rückgängig machen.

Es wird nichts vom Fernseher deinstalliert: Apps werden nur deaktiviert.

### Das Telefon als Fernbedienung

In Lume: Kontrollzentrum, dann die Telefontaste. Code scannen, Zahl eingeben: Es öffnet sich eine Fläche im Stil der Apple-TV-Fernbedienung (wischen zum Bewegen, tippen zum Wählen, halten für Menü) mit Lautstärke, Apps, Suche, Profilen und Szenen auf Fingertipp. Erlaube einmal „Apps vom Telefon öffnen“ (TV Doctor erledigt das für dich).
