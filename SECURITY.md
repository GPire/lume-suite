# Security

TV Doctor talks to a TV over the local network with Android's debugging protocol. It only does this after the person at the TV presses Allow. It never sends anything about your TV to the internet.

Please report a vulnerability privately through GitHub's **Report a vulnerability** button on the Security tab, not in a public issue.

If you cannot use that button, write to the maintainer: giorgiopiredda96@gmail.com <!--contact-->. For anything that is not a vulnerability (a TV that does not work, a translation, an idea) open an issue or a discussion: it helps the next person too. Reports of real TVs are the most valuable thing you can send.
