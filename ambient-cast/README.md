# Lume Cast

An AirPlay and DLNA receiver for Android TV and Fire TV, derived from CastBay 1.8.9 by weenas (GPL-3.0). The original README is kept as `README.castbay.md`.

Changes in this version: new name, logo and screens; calm motion and an idle screen that draws nothing; a Health page; the Wi-Fi band and signal on the home screen with guest-network warning; lyrics that glide and fill as they are sung; Italian, English, Spanish, German, French and Portuguese; no automatic update check (it no longer looks at the original project's releases).
